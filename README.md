


## Bachelor's Thesis

### 📌 Overview

This study presents the design, optimization, numerical modelling, and experimental validation of air-transparent acoustic metamaterial windows aimed at achieving simultaneous noise reduction and natural ventilation.

The study investigates resonant metasurface-inspired unit-cell configurations using ANSYS and combines analytical validation, numerical simulation, machine learning, multi-objective optimization, and experimental testing.

---

## 🎯 Objectives

- Design an air-transparent acoustic metamaterial for simultaneous noise reduction and natural ventilation.
- Investigate resonant cavity-based configurations using ANSYS.
- Validate the numerical model using analytical acoustic theory and existing literature.
- Analyze the trade-off between acoustic attenuation and airflow performance.
- Develop a Random Forest surrogate model for performance prediction.
- Perform multi-objective optimization using NSGA-II.
- Refine multi-hole configurations for improved acoustic attenuation.
- Experimentally validate the optimized frequency-selective resonant design.

## 📊 Key Results

- **22.5 mm cavity:** Achieved **25–37.5 dB transmission loss** in the 900–1500 Hz frequency range.
- **432 design configurations** were generated and analysed to investigate the trade-off between acoustic attenuation and airflow.
- **Aperture diameter** was identified as the most influential design parameter for both acoustic and flow performance through correlation analysis.
- **Random Forest Regression + NSGA-II** were used for surrogate-assisted multi-objective optimization.
- Multi-hole configurations achieved **up to 30–50 dB transmission loss** through enhanced scattering and path-difference effects.
- A frequency-selective resonant design was experimentally validated using **insertion loss measurements**, showing close agreement with numerical predictions.
